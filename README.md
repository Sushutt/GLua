# GLua
The worst Lua addon for Godot.

This project is purpose-built for modding in my own games. You are free to use this in any* way you want, but do note that it is compiled for double-precision builds of godot by default and does NOT add Lua as a scripting language to Godot.

*you may use this as outlined in the [License](https://github.com/Sushutt/GLua/blob/88fb549a516a592e08630a3f052252dff6493084/LICENSE)

## Features
- An easy to set up "LuaScript" node
- Interoperability with Callables and (some) Variants
